# RixoraAI

RixoraAI — десктопний чат-клієнт на Qt 6 / QML з довготривалою пам'яттю,
голосовим введенням та локальним озвучуванням відповідей. Спілкується з Google Gemini,
запам'ятовує факти про користувача та використовує їх у наступних діалогах.

## Можливості
Потокові відповіді Gemini (SSE) із зупинкою генерації.
Тришарова пам'ять: останні повідомлення, rolling-зведення, довготривалі факти.
Гібридний пошук по пам'яті: BM25 + ембедінги, recency-загасання, MMR.
Автоматичне вилучення фактів із листування та фоновий бекфіл старих ділянок.
Голосове введення через Groq Whisper (whisper-large-v3).
Локальне озвучування відповідей на Sherpa-ONNX Supertonic 3 (без хмари).
Історія чатів з індексацією та атомарним збереженням.
8 мов інтерфейсу, режим «пам'ять лише для цього чату».
Автотести логіки пам'яті (QtTest).


## Архітектура

Проєкт складається з двох цілей:

RixoraCore — статична бібліотека з усією логікою: мережа, пам'ять,
персистентність, аудіо, конфігурація.
appRixoraAI — виконуваний файл: main.cpp та QML-інтерфейс
(QML-модуль RixoraAI).

Основні шари:

Мережа та Gemini: NetworkManager (фасад для QML), GeminiClient (сценарій
запиту), GeminiApi (HTTP/SSE), GeminiResponseParser (валідація відповіді),
GeminiAdapter (нормалізація історії), ApiConfigManager (ключі).
Пам'ять: MemoryManager (коротко/середньострокова), MemoryContextBuilder
(збирання контексту), MemoryOrchestrator (вилучення фактів),
LongTermMemory + LongTermMemoryCore (факти), MemorySearch + BM25Index
(пошук), TextTokenizer, TextUtils, MemoryLang.
Персистентність: ChatPersistence + ChatManager (JSON-чати та індекс),
LongTermMemoryPersistence (бінарний формат із CRC32).
Аудіо: AudioEngine (фасад), SpeechApi (STT), TtsEngine (TTS),
AudioPlayback, AudioRecording.

## Як проходить запит
QML передає текст у NetworkManager.
MemoryContextBuilder збирає контекст: зведення, останні повідомлення та
релевантні факти (topK 8, поріг косинуса 0.16).
GeminiAdapter нормалізує історію, GeminiApi надсилає запит.
Відповідь приходить потоком; чанки відображаються одразу.
Після накопичення повідомлень MemoryOrchestrator вилучає факти, а
MemoryManager за потреби оновлює зведення.

## Пам'ять
Короткострокова: вікно останніх 34 повідомлень.
Середньострокова: rolling-зведення чанками по 34 повідомлення.
Довготривала: факти з ембедінгами, до 2000 штук, із провенансом
на чат і повідомлення, дедуплікацією та денним лімітом вилучень.
Пошук гібридний: BM25 + векторна близькість, recency-загасання
(напіврозпад 45 днів), MMR для різноманітності.

## Голос
Введення: запис WAV 16 кГц моно → Groq Whisper. Мову можна фіксувати
або визначати автоматично.
Виведення: локальний синтез Supertonic 3 через Sherpa-ONNX у фоновому потоці,
відтворення через QMediaPlayer, тимчасові файли видаляються.

## Зберігання даних
Чати: JSON у каталозі даних застосунку (chats/), атомарний запис,
індекс .chats_index із самовідновленням.
Довготривала пам'ять: бінарний файл із версією та CRC32.
Ключі API зберігаються локально.
